# 部署说明（宝塔 + Ubuntu 24）

## 1. 需要上传的内容

```
backend/            全部源码（不要上传 venv、__pycache__）
frontend/dist/      本地已构建好的静态文件
```

本地开发产生的 `venv/`、`node_modules/`、`__pycache__/` 一律不用上传。

## 2. 服务器准备（宝塔）

1. 宝塔 → 软件商店安装：**Nginx**、**MySQL 8.0**、**Python 项目管理器**
2. 数据库 → 添加数据库：库名 `ifungoo_erp`，字符集 utf8mb4，记下密码
3. Python 项目管理器 → 版本选 3.10+（Ubuntu24 自带 3.12 可用）

## 3. 部署后端

```bash
mkdir -p /www/wwwroot/wms
# 上传 backend 到 /www/wwwroot/wms/backend，dist 到 /www/wwwroot/wms/dist

cd /www/wwwroot/wms/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

创建环境配置：

```bash
cp .env.example .env
nano .env
# 修改：DB_USER=wms  DB_PASSWORD=宝塔数据库密码  SECRET_KEY=随机长字符串
```

启动测试：

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
# 看到 "Uvicorn running" 即成功，首次启动自动建表 + 创建默认账号 admin/admin123
```

确认可用后，用 **Python 项目管理器** 添加项目实现守护：
- 项目路径：`/www/wwwroot/wms/backend`
- 启动文件/命令：`uvicorn app.main:app --host 127.0.0.1 --port 8000`
- Python 版本：与上面 venv 一致

## 4. 部署前端（Nginx）

宝塔 → 网站 → 添加站点（如 `wms.yourdomain.com`，纯静态），然后改 Nginx 配置：

```nginx
location /api {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
location / {
    root /www/wwwroot/wms/dist;
    try_files $uri $uri/ /index.html;
}
```

站点根目录填 `/www/wwwroot/wms/dist` 也行，关键是 `/api` 反代到 8000 端口。

宝塔 SSL → Let's Encrypt 申请免费证书。

## 5. 验证

1. 浏览器打开站点 → 登录页 → admin / admin123
2. 设置 → 用户管理：新增同事账号，改掉 admin 默认密码
3. 供应商 → 采购 → 添加采购 → 产品库存看到数量
4. 出库单申领 → 库存减少；再采购触发补负规则；退料单回补

## 6. 后续更新代码

```bash
# 本地：npm run build（前端有改动时）
# 上传覆盖 backend/ 和 dist/ 后：
cd /www/wwwroot/wms/backend
source venv/bin/activate
pip install -r requirements.txt   # 依赖有变时
# Python 项目管理器里重启项目
```
